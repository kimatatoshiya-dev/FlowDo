プライバシーポリシー

最終更新日: 2026年8月11日

FlowDo（以下「本アプリ」）は、ユーザーのプライバシーを尊重します。本ポリシーは、無料版 v1 における個人情報およびデータの取り扱いについて説明するものです。

1. 運営者

本アプリの運営者（以下「運営者」）に関するお問い合わせは、 お問い合わせページ または support@flowdo.app までご連絡ください。

2. 収集する情報

無料版 v1 では、運営者がユーザーの個人情報を収集・サーバーへ送信することはありません。

  • アカウント登録・ログイン機能は提供しません。
  • タスクの内容、カテゴリー、期限等は、ユーザーの端末内にのみ保存されます。
  • 運営者による Analytics / Crashlytics / クラウド同期は行いません。

3. 端末内のデータ保存

ユーザーが入力したタスクデータは、端末内ストレージに保存されます。 運営者のサーバーへアップロードされることはありません。

端末の紛失、機種変更、アプリのアンインストール等によりデータが失われる場合があります。必要に応じてユーザー自身でのバックアップ等をご検討ください。

4. 第三者サービス

無料版 v1 では、Firebase 等の第三者クラウドサービスを利用しません。将来、有料版等で機能を追加する場合は、本ポリシーを更新し、アプリ内および本サイトで告知します。

5. お問い合わせ

ユーザーからメールでお問い合わせいただいた場合、返信に必要な範囲でメールアドレスおよび問い合わせ内容を利用します。これらはお問い合わせ対応以外の目的では使用しません。

6. 未成年者

本アプリは、13 歳未満の方を対象としていません。13 歳未満の方は本アプリを利用しないでください。

7. ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、本サイトまたはアプリ内で告知します。変更後に本アプリを継続利用した場合、変更後のポリシーに同意したものとみなします。
